# Catálogo de Skills Oficiales Go (`go-agent-skill`)

> Habilidades técnicas y patrones especializados inyectables en la carpeta `.skill/` de proyectos Go.

---

## 📦 Skills Oficiales Disponibles

| Skill | Descripción | Repositorio Remoto |
|---|---|---|
| `go-fiber-gorm-agent-skill` | Patrones para APIs REST de alta velocidad con Fiber v2/v3 y GORM | `Agent-Rules-Ecosystem/go-fiber-gorm-agent-skill` |
| `go-grpc-protobuf-agent-skill` | Microservicios gRPC, Protobuf y streaming bidireccional | `Agent-Rules-Ecosystem/go-grpc-protobuf-agent-skill` |
| `go-plc-modbus-agent-skill` | Comunicación industrial TCP/Ethernet con PLCs y sensores Modbus | `Agent-Rules-Ecosystem/go-plc-modbus-agent-skill` |

---

## ⚙️ Instalación de una Skill

```bash
git submodule add git@github.com:Agent-Rules-Ecosystem/<nombre-skill>.git .skill/<nombre-skill>
```
