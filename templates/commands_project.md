# Registro Vivo de Comandos del Proyecto

| Comando | Origen | Descripción |
|---|---|---|
| `$boot` | Core (`go-agent-rules`) | Bootstrap completo del proyecto Go |
| `$status` | Core (`go-agent-rules`) | Diagnóstico compacto de sesión |
| `$work` | Core (`go-agent-rules`) | Registro de tarea o bug con auto-sincronización |
| `$archi` | Core (`go-agent-rules`) | Auditoría y modularización de arquitectura Hub & Spoke |
| `$learn` | Core (`go-agent-rules`) | Registro de aprendizaje candidato |
| `$close` | Core (`go-agent-rules`) | Cierre de sesión con verificación de tests (`go test`) |
